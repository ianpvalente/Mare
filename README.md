# Maré — agenda

Agenda de área de trabalho leve, com rotinas, feriados, listas, tarefas e alarmes.

## Como baixar

Vá em **Releases → Maré — download** (lado direito desta página) e baixe o arquivo do seu computador:

| Sistema | Arquivo |
|---|---|
| Windows | `Mare-Windows.zip` |
| Mac (M1 ou mais novo) | `Mare-Mac.zip` |
| Linux | `Mare-Linux.zip` |

Não precisa instalar nada além disso.

## Primeira vez abrindo

**Windows:** descompacte e abra `Mare.exe`. Se aparecer "O Windows protegeu o computador", clique em **Mais informações → Executar assim mesmo**. Dá para arrastar o `Mare.exe` para a área de trabalho ou fixar na barra de tarefas.

**Mac:** descompacte e arraste `Mare.app` para a pasta **Aplicativos**. Na primeira vez o Mac bloqueia (o app não é da App Store). Abra **Ajustes do Sistema → Privacidade e Segurança**, role até o aviso sobre o Mare e clique em **Abrir Mesmo Assim**. Depois disso abre normalmente.

**Linux:** descompacte, e se precisar dê permissão com `chmod +x Mare`.

## Onde ficam os dados

Os eventos ficam salvos só no seu computador, num arquivo `mare_dados.json`:
- Windows: `%APPDATA%\Mare`
- Mac: `~/Library/Application Support/Mare`
- Linux: `~/.local/share/Mare`
